# AD Foundation - Beautiful Website Package

## Features Included:
1. **High Quality Visual Assets**: Embedded SVG illustrations for Founder (Rakhi Luthra) and unique course banners for every class.
2. **Interactive Elements**: 
   - Instant "Join Now" modal popup form.
   - Floating WhatsApp Chat button.
   - Hover animations and modern UI cards.
3. **Courses Covered**:
   - Spoken English & Grammar
   - Basic & Advanced Math
   - Science Explorer
   - AI & Smart Tools
   - Graphic Design & Canva
   - Computer Basics & MS Office

## How to Run:
1. Extract `AD_Foundation_Website_Beautiful.zip`.
2. Open `index.html` in Google Chrome, Microsoft Edge, or any modern web browser.
3. Upload `index.html` directly to Hostinger, Netlify, Vercel, or GitHub Pages for free hosting!
